## Learned Workspace Facts

- HyperWebster-OS lives at `~/Projects/HyperWebster-OS`; public repo is `spundone/HyperWebster-OS` on GitHub.
- Personal Arch desktop ISO flavor forked from NoSignal-OS (`~/NoSignal-OS`); hyperarch / HyperWebster / Starman branding lineage.
- Live installer uses a HyperWebster OS-branded, Omarchy-inspired `gum` TUI with Starman art and stepwise install flow; do not pipe multiline Starman ASCII through `gum style` (it strips trailing spaces), and keep user-visible clear/status on `/dev/tty`. Live ISO tty2 login is `root` with an empty password. Post-install `hyperwebster-update-check` / `checkupdates` must use timeouts so offline installs do not hang.
- ISO builds use `./build.sh` for Arch native or containerized OrbStack/Docker Desktop/WSL2; on Apple Silicon OrbStack force `linux/amd64`, disable pacman alpm sandbox, and keep the AUR chroot and unsquash work tree on case-sensitive Docker volumes (not macOS bind mounts: virtiofs rejects `.arch-chroot`, and APFS collides on paths like `xt_connmark.h` vs `xt_CONNMARK.h`); nested `systemd-nspawn` in Docker needs `machine-id`, a propagate tmpfs, and `--keep-unit`; `hyperwebster.sh` auto-downloads the latest Arch ISO and uses mirror failover.
- Shell still builds from upstream `28allday/nosignal-shell` (branded and packed as a tarball for makechrootpkg; directories are not copied into the chroot) until a `hyperwebster-shell` fork exists; local shell work often uses `offline/aur/nosignal-shell.fork`; Nexus overlays such as `colours-page` and `shell-branding` live under `os updates/`.
- Layer components live under `os updates/`; `hyperwebster-update` pulls the layer from GitHub, skips rsync when trees already match, and supports `--force-migrations`; migrations must tolerate already-identical files and optional hardware gaps so the runner does not abort the whole update; session menu Shut down/Reboot/Hibernate/Logout go through `session-power` (`hyperwebster-session-power` → systemctl/uwsm) because caelestia's async logind PowerOff path can silently no-op.
- Gaming/TV focus: Limine Starman boot, Deckify/gamescope/Chimera, LUKS2 with TPM auto-unlock and Omarchy-style Plymouth fallback; `systemd-cryptenroll` must use `--unlock-key-file` (not `--unlock-passphrase`); public docs describe generic 4K HDR VRR TV gaming without personal hardware; Super+Shift+S enters the gamescope gaming session only when the expected DeckShift/Chimera session desktop file is present; Super+Shift+R exits back to the desktop via the Steam/CachyOS session path (`gamescope-session.target` stop through `hyperwebster-exit-gaming` / hotkeyd), not an SDDM restart; Limine HyperWebster/HyperArch submenu should prefer and auto-boot `linux-cachyos` (including indented `//linux-cachyos` rows); Non-Steam titles (Epic/Heroic, emulators, local games) and Millennium/Lua Steam mods integrate via `os updates/nonsteam-gaming/` into the gamescope SteamUI (including Decky CEF/QAM ensure services); Starman gaming-boot and DeckShift SDDM autologin must stay gated so `zz-steamos-autologin` does not skip the gaming session; desktop gamepad UX lives in `os updates/controller-desktop/` (profile chords use Linux face names `BTN_SOUTH`/`BTN_EAST`, not `BTN_A`/`BTN_B`; Guide+B closes windows) and must not steal input from Steam/gamescope; gamepad wake-from-sleep is `os updates/gamepad-wakeup/`.
- CachyOS optimized kernel and kernel manager ship out-of-the-box by default.
- Tailscale is preloaded for remote access; iPhone USB tethering ships via `28allday/omatether` with NetworkManager + networkd coexistence.
- Keeps NoSignal/caelestia desktop look with light/dark theme polish (SDDM sync, GTK bridge); Nexus Colours (`os updates/colours-page/`) drives caelestia Material schemes; scheme mode and palette live in `~/.local/state/caelestia/scheme.json` (not `shell.json`), and `smartScheme` plus a bright wallpaper can flip Nexus to light Material You; nsbar `Theme.fontFamily` must stay JetBrainsMono Nerd Font (not GoogleSansFlex), and `Theme.barBg` must not bind `Colours.transparency` or `Theme.size`/`barHeight` breaks; notification toast surfaces need palette alpha above Hyprland `ignore_alpha` (prefer layer-0/base over thin layer-1) so frosted blur applies; drawer z-order fixes live in `os updates/drawer-stacking/`; Omarchy wallpapers wire into the Caelestia picker via the omarchy-themes layer; middle-button hold-to-scroll is the `button-scroll` layer; monitor overlays live under `~/.config/caelestia/monitors/`; start caelestia shell inside an active Hyprland session, not a bare tty. Additions rounding/blur toggles are binary, while continuous appearance scales live in `shell.json` / `shell-tokens.json`.
- Secondary drives premount at boot via the `drive-automount` layer component (lsblk JSON discovery so exFAT/NTFS labels with spaces mount under `/mnt/<label>`; desktop-user uid/gid for Steam; Settings → System tools → Drives for remount/ignore).
- Session lock is Caelestia Quickshell `WlSessionLock` (hyprlock may be packaged but is unused); SDDM is the login greeter only (`os updates/sddm-theme/`, including `sddm-theme-sync` and `hyperwebster-greeter-pad`); greeter should visually twin the lock screen, with a Starman/gamescope entry path from the greeter.
